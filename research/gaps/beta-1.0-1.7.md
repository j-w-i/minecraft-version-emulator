# Gap audit — Beta 1.0, 1.2, 1.3, 1.4, 1.5, 1.6, 1.7.3

Scope: the seven declared `Beta` profiles (`beta_1_0`, `beta_1_2`, `beta_1_3`, `beta_1_4`, `beta_1_5`,
`beta_1_6`, `beta_1_7_3`). Beta 1.1, Beta 1.2_01/02, Beta 1.3_01, Beta 1.4_01, Beta 1.5_01/02, Beta 1.6.x
and Beta 1.7/1.7_01/1.7.2 are **intentionally not declared**; where a declared profile stands in for one of
them it is said so in that version's header. (Release 1.1 and Release 1.2.5 *are* declared in the matrix, but
they are outside this audit — this file covers the Beta family only.)

## Method and honesty rules used here

* **ACTUAL** side: `research/version-facts.md` (generated from the runtime APIs by `VersionFactsTest`; read
  only, never edited). Where the facts file is ambiguous (a rule that says "modern drop tables", or a food
  table of "none") the runtime class that consumes the rule was read to establish what the player actually
  sees, and that source is named in the row. No Gradle was run and no world was generated for this audit, so
  nothing here is claimed as a runtime measurement — it is a static cross-check of the actual model against
  the historical record.
* **EXPECTED** side: `minecraft.wiki` per-version pages fetched with `?action=raw`, plus feature pages for
  cross-cutting facts. Every expected claim carries a short quote and an evidence key (E1…E26); the full
  quote and URL for each key are in [Appendix A](#appendix-a--evidence-keys). A row that cannot be settled
  from the fetched sources is marked `UNKNOWN` and the row says what would settle it.
* **Declared profile vs artefact.** `beta_1_7_3` is also the catalogue's proxy for *Beta 1.7* (the project's
  own `Feature.PUNCH_TNT` evidence says so), which is safe because 1.7.1–1.7.3 are bug-fix releases of the
  same 30 June 2011 content; the bugs those patches removed (piston duplication, the block-36 crash) are
  therefore *not* expected in this profile. `beta_1_0` is the initial b1.0 artefact, not `Beta 1.0_01`.
  Beta 1.3 and Beta 1.4 each had same-day reuploads (debug-loadout code, `research/historical-bugs.json`
  records it); the audit assumes the declared profile is the final reupload, which the wiki's own page
  describes as the downloadable "Beta 1.3b" for 1.3. Confidence on that assumption: medium — see §9.
* **Gap types.** `MISSING` (the version had it, the mod does not), `WRONG` (present but different),
  `EXTRA` (the mod has it, the version did not), `UNKNOWN` (evidence insufficient — never a guess), and
  `MATCH` (checked, no difference found; recorded so "nothing missing" is itself evidenced).
* **Severity**: H = a normal player meets it in the first hour; M = meets it in ordinary play; L = niche,
  cosmetic or only reachable with effort.
* Every version table covers the same set of domains (blocks/items, crafting, smelting, mobs, movement, combat, health/hunger/food, XP/enchanting/brewing, inventory, weather/day-night, Nether/End, structures/villages, biomes/decoration, ores, height/bedrock/sea level, visuals, UI); a row count varies from 18 to 22 because a domain splits into more rows where a version has more evidence (e.g. mob drops split into hostile/animals/Nether).

## 8. Top 10 highest-impact gaps

Ranked by how soon a normal player meets them and how much they change play. All are evidenced above.

1. **Mob drops are the modern tables for every profile except four 1.7.3 mobs.** Zombies drop rotten flesh +
   iron/carrots/potatoes, spiders drop spider eyes, cows drop beef, chickens drop raw chicken, ghasts drop
   ghast tears and zombie pigmen drop gold/rotten flesh instead of 0–2 cooked porkchops — items that did not
   exist in any of these builds, in every one of the seven versions (rows 1.6/2.7/2.8/3.5/4.6/5.5/6.5/7.5).
2. **Sheep death drops and shearing are wrong in both directions.** Killing an unshorn sheep yields wool in
   Beta 1.0–1.6 where it should yield nothing, and shears in 1.7.3 give 1–3 wool instead of the documented
   2–4 (rows 1.7, 2.7, 7.5).
3. **Slimes spawn in Beta 1.0 although slime spawning was disabled from Alpha 1.2.0 and only returned in Beta
   1.3** — the one spawn-set error among seven otherwise-correct sets (row 1.5).
4. **Player damage is 1 point low in Beta 1.5/1.6/1.7.3** because the documented "+1 to all player attacks
   unless moving upwards" bug is not modelled, and unarmed damage is 1 instead of 2 (rows 5.8/6.8/7.8).
5. **Cookie stacking (Beta 1.4+).** The first stackable food cannot stack: all pre-1.8 food is forced to
   size 1, so a stack of 8 cookies is impossible in 1.4/1.5/1.6/1.7.3 (rows 4.10/5.9/6.9/7.9).
6. **Cake does nothing.** Every version from Beta 1.2 onwards heals 3 health per slice by right-click; the mod
   records the value but applies nothing (rows 2.12/3.9/4.10/5.9/6.9/7.9).
7. **Golden apples cannot be crafted in any of the seven versions** even though the apple+8-gold-block recipe
   existed throughout (rows 1.3/2.3/4.3/7.2).
8. **Pre-1.6 fire, minecart boosters, missed-swing cooldown and water-source behaviour are not modelled.**
   Beta 1.0–1.5 get 1.6's nerfed fire spread, no minecart boosters, and (for 1.6+) still take the 10-tick
   missed-swing penalty; below-source water acts as a source only where 1.5 didn't (rows 6.8 and the
   Beta 1.0–1.5 world/combat rows that cite [E9c/E9e/E9l/E9r]).
9. **Crafting output counts are modern.** Slabs give 6 instead of 3, ladders 3 instead of 2, and pre-1.3
   pressure plates 2 instead of 3 — a systematic resource-economy difference across all seven profiles
   (rows 2.4/3.2/4.3/5.2/6.2/7.2).
10. **Achievements are modern advancements.** Beta 1.0–1.3 should have none, Beta 1.4 partial infrastructure,
    Beta 1.5+ exactly 16 achievements and statistics; the profiles expose the full modern advancement graph
    instead (UI row in each version).

Honourable mentions (real but niche): Beta 1.0 birch/spruce tree generation unverified; pre-1.6 ore quadrant
bias absent; Beta 1.2/1.3 lapis ore parameters and drop count unresolved; pre-1.6 grass/foliage colour maps
present too early; Nether bed explosion present in 1.3–1.5; Beta 1.3–1.5 set the respawn point from beds.

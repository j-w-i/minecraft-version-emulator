## Reproduction and method

With an installed JDK and the three retained jars:

```powershell
$env:JAVA_HOME='C:/Program Files/Java/jdk-25.0.4.1'
python scripts/extract-early-gameplay.py
```

[The Python driver](<../scripts/extract-early-gameplay.py>) re-fetches independent metadata and checks BOTH SHA-1 and length before executing [the independent Java reflection tool](<../scripts/EarlyGameplayExtractor.java>) in an isolated historical-jar class loader. It reads the initialized crafting manager (`net.minecraft.a.b.a.f`, list `b`), exact pattern dimensions/ingredient IDs/result/count, and the furnace's private integer smelt function (`net.minecraft.a.a.b.a.b.d(int)`). It reads registered food instances and their actual inherited heal fields, not English-name strings.

Obfuscated food field triples (food class, heal field, item numeric-ID field): Indev `p.as / i.ap`, April `p.au / i.ar`, June `r.aw / i.at`. Stew subclasses inherit the food heal field and are included. Bytecode inspection confirms the food use path decrements the stack and calls the player's direct-heal method; June class `net.minecraft.a.b.r.a(stack,world,player)` calls `player.b(int)`. Counts and pattern tables were separately cross-checked against full `javap -p -c` output retained in the ignored research cache.

Authoritative generated resources: [Indev](<../src/main/resources/data/historical_experience/early_gameplay/indev_latest.json>), [April Infdev](<../src/main/resources/data/historical_experience/early_gameplay/infdev_420.json>), [June Infdev](<../src/main/resources/data/historical_experience/early_gameplay/infdev_611.json>).
